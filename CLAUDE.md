# Лаборатория нестабильных порталов — контекст проекта

Тестовое задание на вакансию AI-first Developer в MOX, вариант «Лаборатория
нестабильных порталов». Срок сжат до 2–3 дней.

## Перед началом работы

1. Прочитать `docs/PLAN.md` — там чеклист статуса и метка «остановились здесь».
2. Посмотреть `git log --oneline -15`.
3. Не переделывать то, что уже отмечено галочкой.

## Команды

| Команда | Что делает |
|---|---|
| `npm install` | установка зависимостей |
| `npm run dev` | локальный запуск |
| `npm test` | тесты домена (Vitest) |
| `npm run build` | сборка в `dist/` |

## Стек

Vite + React 19 + TypeScript + Vitest. Деплой — GitHub Pages через
`.github/workflows/deploy.yml` при push в `main`.

## Где что лежит

```
src/domain/    чистый TypeScript без React — вся логика и правила
src/state/     useReducer + Context поверх домена
src/ui/        компоненты (только отрисовка)
src/styles/    единая таблица стилей
docs/PLAN.md   чеклист статуса
docs/worklog.md  черновик AI Worklog
```

## Правила, которые нельзя нарушать

- **Ни одной формулы и ни одного запрета внутри компонентов.** Расчёт риска
  живёт в `domain/risk.ts`, запреты — в `domain/rules.ts`. Компоненты только
  показывают то, что вернул домен.
- **Никакой случайности в домене.** Ни `Math.random`, ни `Date.now` — иначе
  сценарии перестанут быть воспроизводимыми и тесты поплывут.
- **Запрет объясняется до нажатия.** Кнопка недоступного действия —
  `disabled`, причина из `checkAction` выводится рядом. Никаких `alert`
  после клика.
- **Worklog ведётся по ходу.** Как только AI предложил неудачное решение или
  ошибся — сразу строка в `docs/worklog.md`. Задним числом это не восстановить,
  а честность здесь прямо оценивается.
- **Секретов в проекте нет** — внешние API не используются. Если появятся,
  только через переменные окружения, никогда в коде.

## В конце каждой сессии

По фразе «зафиксируй прогресс»: проставить галочки в `docs/PLAN.md`, передвинуть
метку «остановились здесь», дописать `docs/worklog.md`, сделать коммит с внятным
сообщением.
